# postgres-pool-monitor 🐘

> Lightweight connection pool health visualizer and query latency watcher for Node.js & pg.

[![Node.js](https://img.shields.io/badge/Node.js-18%2B-green)](https://nodejs.org)
[![PostgreSQL](https://img.shields.io/badge/PostgreSQL-14%2B-blue)](https://postgresql.org)

## Features
- Real-time idle vs waiting connection tracking.
- Slow query alerts with configurable latency thresholds.
